# technical_challenge

Technical Challenge for Outsera

## Requirements

- [Node.js](https://nodejs.org/) `^22.22.3`, `^24.15.0`, or `>=26.0.0`
- npm `>=8`

The app reads movie data from `https://challenge.outsera.tech/api/movies`, so the machine needs network access while it is running.

## Run

```bash
npm install
npm start
```

`npm start` serves the app at [http://localhost:4200](http://localhost:4200).
